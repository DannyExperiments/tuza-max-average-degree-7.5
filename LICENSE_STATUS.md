# Rights and data licenses

The original manuscript, expository material and project verification programs are supplied for inspection. The project has not selected a blanket license for redistribution of these materials. Scholarly citations identify the sources of external theorems.

Gupta’s numerical certificate data and Brendan McKay’s graph catalogues retain their original **Creative Commons Attribution 4.0 International** terms. The verification data guide identifies the creators, exact files, original sources, digests and any transformations. The repository-wide license status does not change the permissions granted for these data. [Data credits](verification/DATA_SOURCES.md) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
