# Reporting a security issue

Use the repository’s private reporting channel if available, or contact the repository maintainer through a private channel you already share. Provide the affected commit and file, a description of the issue, and the verification step involved. Keep credentials and private machine information out of reports.

The local finite checks use bundled data. The hosted workflows use read-only repository permissions and pin external actions by commit. The PDF workflow also pins its typesetting image by digest. [Replay instructions](REPRODUCIBILITY.md)
